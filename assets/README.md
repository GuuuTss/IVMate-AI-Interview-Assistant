# 展示素材说明

本目录仅收录 IVMate 官网已经公开的标志与教程截图，不收录个人上传的简历、原始文档、私人会话截图或客户端数据目录。

| 文件 | 公开来源 | 用途 |
| :--- | :--- | :--- |
| `ivmate.png` | [官网标志](https://rocketman.top/ivmate-icon-128.png) | 产品标志 |
| `screenshots/interview-answer.png` | [面试教程截图](https://rocketman.top/guide-assets/interview-answer-macos.png) | 展示语音识别与回答呈现 |
| `screenshots/home.png` | [首页教程截图](https://rocketman.top/guide-assets/home-macos.png) | 展示客户端首页 |
| `screenshots/records.png` | [记录教程截图](https://rocketman.top/guide-assets/records-macos.png) | 展示本地会话列表与导出入口 |

图片沿用教程真实画面，仅清除 EXIF / XMP 等附加元数据，像素内容未变，未生成或改绘产品界面。首页和记录页为较早版本的访客界面。截图中的版本文字、时长和记录数量仅用于展示；其中旧的“记录面试”入口已更名并改造为“个人档案”。

笔试教程中包含浏览器工具栏和书签的画面未复制到本仓库；相关实际效果可通过官网[笔试教程](https://rocketman.top/guide/exam/)查看。

产品名称、标志及截图的权利说明见 [NOTICE.md](../NOTICE.md)。

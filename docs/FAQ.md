# 常见问题

[← 返回产品介绍](../README.md)

## 去哪里下载最新版？

打开 [IVMate 官网下载页](https://rocketman.top/download/)。本仓库展示产品，不分发安装包；下载页提供当前版本与对应的系统要求。

## Mac 应该选择哪个版本？

在苹果菜单中打开“关于本机”。显示 Apple M 系列芯片时选择 Apple Silicon 版；显示 Intel 处理器时选择 Intel 版。两个芯片版本是独立的安装包。

## 能识别什么声音？

面试模式识别这台电脑播放的系统声音，例如会议中对方的提问。先确认对方声音在电脑扬声器或耳机中正常播放，再检查客户端提示的系统权限与连接状态。

## 是否必须先上传简历？

不必须。可以直接启动助手；完善个人档案后，面试回答能够结合简历、经历细节与本场问答上下文。简历在“个人档案”维护，更换文件时再重新整理。

## 长期记忆和对话记忆有什么区别？

长期记忆是保存在本机、可持续维护的个人经历资料。本场对话记忆用于当前面试会话中的连续问答。两者用于面试模式，不会把面试上下文混入笔试模式。

## 笔试可以提交几张截图？

同一题最多 **6 张**。尽量完整包含题干、输入输出示例与约束，再按 `Ctrl + J` 提交。具体操作见[笔试教程](https://rocketman.top/guide/exam/)。

## Mac 的 Ctrl 是 Command 吗？

不是。`Ctrl + B / G / H / J` 中的 Ctrl 均指 Control。移动窗口才使用 `⌘ + 方向键`。客户端顶部会显示当前可用的快捷键。

## 档案和记录会自动同步到另一台电脑吗？

不会自动同步。本地档案与记录属于当前电脑的数据。在线语音识别、文档整理与 AI 回答仍需要将相应输入交由在线服务处理，不能理解为完全离线运行。

## 为什么截图与当前客户端不完全一样？

仓库复用了官网公开教程中的真实截图，部分来自早期版本。首页“记录面试”已更新为“个人档案”；界面文字、版本号和权益信息以当前客户端与官网为准。

## 如何反馈问题？

优先查看[官网排查教程](https://rocketman.top/guide/troubleshooting/)。提交 Issue 时，请描述系统版本、芯片、客户端版本、操作步骤及实际现象。不要上传手机号、验证码、私人简历、原始面试记录或带凭据的日志。
